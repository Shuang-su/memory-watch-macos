# 实施计划

- 原生 App 默认启用 SceneKit 缩略图自动保护，阈值固定为 4 GiB，每 5 秒采样；独立于普通提醒阈值。
- 只处理当前用户、准确系统可执行文件路径对应的 `SceneKitQLThumbnailExtension`；其他进程及 Python CLI 保持只提醒。
- 发出 SIGKILL 前重新校验 PID、启动时间、路径、用户和内存占用，身份变化或占用回落则跳过。
- 记录信号发送结果，延迟检查原进程是否退出，区分成功、失败和尚未确认；同一实例每 60 秒最多尝试一次。
- 提供持久保存的菜单开关，暂停监控时同时暂停自动退出；维持纯图标和异常红色提示。
- 测试边界、误匹配、PID 重用、权限、回落、失败重试及真实一次性子进程的信号与退出；不制造内存耗尽。
- 版本更新为 1.1.0，更新本机 App，沿用登录自启动；保持项目的构建、CI 和发布验证流程。

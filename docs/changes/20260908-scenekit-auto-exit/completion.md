## 边界

- 采样间隔为 5 秒，无法保证在系统完全失去响应前处理所有突发增长。
- 强制退出会中止该进程的缩略图任务；访达可能再次启动新实例。未知路径或不可读取的进程不会自动终止。
- 信号投递成功与确认进程退出分别记录；无法确认时不会报告为已成功退出。
